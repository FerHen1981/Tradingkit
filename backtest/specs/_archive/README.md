# Archived single-indicator demo specs

These were the early one-mechanism demo strategies (bb_revert, bos, choch, …).
They are single-indicator and no longer belong in the Strategy Library now that
strategies are composed by role (the 4th-variant builder + the role-composing
sampler). Kept here for reference; the Lab only lists `specs/*.yaml`, so anything
in this subfolder is out of the library. Restore by moving a file back up one level.
